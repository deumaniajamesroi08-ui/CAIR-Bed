# CAIR-Bed
### AI-IoT Based Real-Time Health Monitoring System for Bedridden Patients

## Project Overview
CAIR-Bed is an AI-IoT-based health monitoring system designed to help monitor the condition of bedridden patients in real time. The project aims to support caregivers by providing patient monitoring data through a digital system.

## Objectives
- Monitor patient health information in real time.
- Support caregivers in observing bedridden patients.
- Organize and display patient monitoring data through a dashboard.

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Key Features
- User login and registration
- Patient monitoring dashboard
- Patient data management
- Database integration

## Installation
1. Install XAMPP.
2. Extract the project files into the `htdocs` folder.
3. Start Apache and MySQL through the XAMPP Control Panel.
4. Import the project database using phpMyAdmin.
5. Configure the database connection settings.
6. Open the project in your browser using `http://localhost/`.
